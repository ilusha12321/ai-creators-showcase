# Persona — AI creators landing

```
npm install
npm run dev
npm run build
```

- Telegram URL: `src/config.ts`
- Portraits: put `alex.webp`, `noah.webp`, `mia.webp`, `emma.webp` into `src/assets/creators/` (prompts in `docs/ai-prompts.md`). Missing files show a tinted placeholder, so the build never breaks.
- Creator data: `src/data/creators.ts`
